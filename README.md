# 提示词优化（PromptForge）

DSH 提示词优化插件。输入框有文字时，在发送控件旁显示提示词优化按钮；点击后显示加载动画，调用 DSH 已配置的模型重写草稿。结果只替换输入框，不自动发送。

## 使用

1. 在 DSH 的「设置 → 提示词优化」中选择模型和思考强度，也可以修改优化指令。模型列表来自当前 DSH 的模型目录。
2. 输入草稿，点击提示词优化按钮，等待优化完成。
3. 检查结果，再自行发送。

优化是独立模型请求，不会修改聊天会话的模型或思考强度，也不会作为聊天消息写入会话。请求期间若编辑草稿、提交消息或切换会话，较晚返回的结果会被丢弃。调用失败时保留原草稿，可在设置页查看错误。

### 默认改写方式

默认在原意内适度展开：功能需求可明确相关细节，分析和设计任务可补充有用的观察维度；不强制固定模板，也不默认采用最小改写。画面或主题描述可以整理表达与描述重点，但不会自动改成写作、绘图或视频任务，或指定未给出的时间与天气。

已有自定义指令保持不变。如果设置中保存了旧指令，点击“恢复默认”可使用更新后的默认指令。

### 自动引用文件与技能

「设置 → 提示词优化 → 自动引用」有两个开关，默认都开启。开启后，同一次点击会多做一步：模型在改写的同时提名它认为这次任务需要的文件与技能，Host 再逐条校验，命中的引用被追加到提示词末尾。

- **文件**：模型只给路径或路径片段，Host 拿当前会话工作区的文件索引核对，只有真实存在的路径才会变成 `@路径` 引用（含空格的路径按 DSH 语法写成 `@"路径"`）。模型编造的路径不会出现。
- **正文不会被引用吃掉**：引用是「agent 该打开什么」的索引，永远不是正文的替代。若某条提名对应的名字原本写在草稿里、却在改写后从正文消失，会保留原稿，并在按钮提示和设置页说明；不会把「检查与的登录逻辑是否一致」这种被抽空的句子写回输入框。
- **技能**：与文件同样的两段式——模型只给技能名，Host 拿该会话可见的技能目录核对，且只保留模型可调用的技能；命中的技能以名称列在末尾的技能块中，由 agent 按需用 `skill` 工具加载。
- 文件与技能**各自独立兜底**：任一侧为空，Host 就会把那一侧的真实候选列出来再问一次（文件列路径、技能列目录）。模型看不到技能目录，所以「帮我写一份简历」这类请求若不给候选，它就只会回答「没有相关技能」——这是 `office-docx` 之类技能能被引用到的前提。
- 引用只增加提示词体积，不内联文件内容：agent 仍按需用 `read` 工具去读。
- 目录引用会校验目录自身，不会替换为某个子文件；路径片段有歧义时不会猜选。
- 已有文件引用与技能块会合并去重；超过输入框长度上限时省略新增引用，保留正文。
- 候选发现优先查任务中的路径，再尝试根目录和受限遍历；旧索引不支持根目录列表时使用任务目录和常见目录名。
- 引用处理总预算为 15 秒。结果会显示在按钮提示与设置页，区分引用已确认、未发现相关引用、处理未完成和原稿已保留。数量只统计本次新增的引用。

关掉开关后，输出格式回到纯文本，模型也不会再收到提名要求。

耗时：改动只在需要时发生。工作区索引已热时，一次点击约 2 秒（无需提名）到 3 秒（含提名与校验）；首次访问某个工作区要为索引付一次全量扫描，可能到十几秒。

## 安装

两种方式任选其一。

**1. 通过 DSH 插件界面**

进入 DSH 的插件 → 添加插件，输入：

```
https://github.com/Super-Gagaga/PromptForge.git
```

**2. 克隆后本地构建**

克隆本仓库并构建，再重启 DSH 或重新加载插件：

```powershell
git clone https://github.com/Super-Gagaga/PromptForge.git
cd PromptForge
npm test
```

为可由 CLI 管理的 profile 安装时，将下面的 `<profile>` 换为实际名称、`<path>` 换为本仓库路径：

```powershell
dsh plugin --profile <profile> add 'link:<path>/PromptForge'
```

桌面 profile 由 Electron 应用管理，CLI 不支持直接启动它。插件通过 `package.json` 的 `dsh.bundle` 与 `dsh.client` 字段和本包的 `cordis.patch.yml` 装配，Host 与浏览器半体共同生效。

## 开发与验证

需要 Node.js，无需安装额外构建依赖。

```powershell
npm run build
npm test
```

编辑 `src/`，不要直接修改生成文件。构建会同步生成 `lib/index.js`、`lib/client.js` 及根目录镜像。

- `src/host.js`：设置读写、模型调用和 HTTP 接口。
- `src/client.js`：提示词优化按钮、草稿替换、设置页和中文/英文文案。
- `src/shared.js`：默认优化指令和限制。
- `locale/`：插件列表展示的标题与描述（`zh` / `en`），由 DSH 读取，构建不改写。
- `tools/selfcheck.mjs`：隔离设置目录的自动自检，覆盖插件加载、请求、草稿边界、设置保存、失败处理与自动引用校验。

设置保存在 `$DSH_HOME/prompt-forge.json`；未指定 `DSH_HOME` 时使用用户目录的 `.dsh/prompt-forge.json`。每次优化最多接受 60,000 字符，输出上限 4,096 tokens，请求超时 120 秒。

## 常见问题

若出现 `pending (waiting for service: optional)`，应更新到本项目当前构建并重新加载。当前 DSH Cordis 将 `inject` 对象的键解释为服务名，不支持 `inject: { optional: [...] }`。本插件使用按需服务获取，避免阻塞顶层启用。
